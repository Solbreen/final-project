# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

## Веб-приложение "Менеджер задач"

Итоговый проект создан для подтверждения закреплённых навыков.

Приложение позволяет пользователю отслеживать поставленные им задачи. Есть возможность устанавливать периодичность задачи, редактировать и удалять задачи.

## Список выполненных задач

Выполнены все основные задачи и со звёздочкой, кроме пункта с аутентификацией и докером.

## Инструкция по локальному запуску

Клонируйте репозиторий:

```bash

git clone <repository-url>
cd <repository>
```
Установите зависимости:

```bash

go mod download
```
Запустите сервер:

```bash
go run main.go
```
Откройте в браузере:

```
http://localhost:7540
```

Для кастомного порта используйте флаг -port

```bash
go run main.go -port 8080
```

Если присутствует файл .env, то в нём могут присутствовать переменные TODO_PORT с портом и TODO_DBFILE c путём до базы данных.

Пример:
```
TODO_PORT=7540
TODO_DBFILE=scheduler.db
```

Если переменные указаны, то они выбираются по умолчанию.

Запустите тесты 
```bash
go test ./tests
```
